Product\_Return\_Predictor

Product Return Predictor is web application which is made by integrating machine learning model to predict the possibility a product of being returned or not at the time of ordering by using the past order - returned details.

It is real - world suitable project which shows the proficiency in data explration and modeling :

* Python
* Numpy
* Pandas
* scikit-learn
* matplotlib



Implenmented FastAPI backend and Vite react frontend app
